# Atlas3K documents

These are [Atlas3K](https://github.com/Ironictw2st/Atlas3K)'s notes from Total War: THREE KINGDOMS, carried over at the
fork. They describe 3K's maps, kit and tools, not WH3's. They are kept for their method (Ghidra decompiles, Frida
traces of BOB, byte-level parity diffs) and for the rules the two games share. Code comments in AtlasWH3 cite some of
them as the origin of a rule.

| Document | About |
|---|---|
| [bob_campaign_build.md](bob_campaign_build.md) | Building 3K's `3k_dlc07_main_map` with BOB, step by step, with vanilla parity |
| [guandu_campaign_build.md](guandu_campaign_build.md) | Building a new 3K campaign map (Guandu) end to end |
| [bob_re_tile_placement.md](bob_re_tile_placement.md) | Reverse-engineering notes on 3K's tile placement |
| [bob_re_global_mesh.md](bob_re_global_mesh.md) | Reverse-engineering notes on 3K's global mesh and camera height map |
| [hlp_spd_generation.md](hlp_spd_generation.md) | The first proposal for native hlp/spd generation (superseded by [`../hlp_spd.md`](../hlp_spd.md)) |
| [campaign_tile_editor.md](campaign_tile_editor.md) | Atlas3K's tile-map editor and its web front end (the web editor is cut) |
| [terry_entity_editing.md](terry_entity_editing.md) | Generic Terry entity editing, on 3K projects |
| [battle_map_editor.md](battle_map_editor.md), [battle_editor_plan.md](battle_editor_plan.md) | The Campaign battles window and the cut battle terrain editor |
